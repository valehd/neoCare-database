# NeoCare Database

## Overview

NeoCare Database is a relational MySQL database designed to support maternal and neonatal healthcare analytics.

The project models the maternal-neonatal care pathway, from pregnancy and delivery to newborn assessment and neonatal outcomes.

Developed as part of my transition from NICU Midwife to Software Engineering, combining healthcare expertise with database design and SQL development.
